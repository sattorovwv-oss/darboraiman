# Юсуфчон — личный сайт

Портфолио с 11 проектами, фильтрами, Telegram-ссылками и общими отзывами. Превью проектов — HTML/CSS-композиции по мотивам присланных скриншотов.

## Запуск с отзывами

Для бесплатного хостинга с Supabase сначала выполните [инструкцию](supabase/SETUP.md). Supabase хранит данные, отдельный Python-сервер обслуживает сайт.

Требуется Python 3.10+ (внешних зависимостей нет):

```sh
python3 server.py
```

Откройте http://localhost:8000. Порт меняется переменной `PORT`.

Отзывы хранятся в SQLite: `data/reviews.sqlite3`. Для хостинга задайте `REVIEWS_DB` как путь на постоянном диске и регулярно копируйте этот файл для резервирования. Все экземпляры должны работать с одной базой; для этой версии используйте один сервер. База не публикуется через HTTP. Не храните её в Git.

`GET /api/reviews` возвращает отзывы по дате добавления (новые сверху). `POST /api/reviews` принимает JSON: `name` (2–60 символов), `rating` (целое число 1–5), `comment` (10–2000 символов). Отзывы публикуются после автоматической ИИ-проверки; см. настройку ниже.

## Публикация и статический файл

Для общих отзывов нужен хостинг с Python и постоянным диском. GitHub Pages и `python3 -m http.server` не выполняют API. Домен должен направляться на этот сервер, а HTTPS — завершаться на прокси хостинга.

Скачанный HTML показывает портфолио и форму, но явно отключает отправку отзывов: общая база доступна только при запуске сервера. Отзывы не подменяются локальными данными или демо-примерами.

Контент — `index.html`, стили — `style.css`, сервер — `server.py`. Manrope загружается с Google Fonts; без сети используется Arial.

## Автоматическая ИИ-модерация

Задайте **на сервере** секрет `MODERATION_API_KEY` — API-ключ OpenAI с доступом к модели `gpt-4.1-mini` и работающим биллингом. Не добавляйте ключ в HTML, Git или публичные переменные. Сервер обращается к `https://api.openai.com/v1/responses` (исходящий HTTPS должен быть разрешён). Используется Structured Outputs, `store: false`, таймаут 18 секунд. Имя и комментарий передаются провайдеру; посетитель видит это до отправки. Оценка не передаётся модели.

Только одобренные отзывы сохраняются. При отсутствии ключа, ошибке API или некорректном ответе публикация блокируется. Текст остаётся в форме. Вежливая критика и низкие оценки разрешены; оскорбления, мат и спам отклоняются. ИИ может ошибаться: абсолютная защита от спама не гарантируется.

Индикатор работает минимум 5 секунд, запрос начинается сразу; при более долгой проверке загрузка продолжается. Отправка ограничена одной попыткой с IP за 30 секунд, одновременно проверяются до 4 отзывов. Ограничение находится в памяти и сбрасывается при рестарте; за reverse proxy настройте отдельный лимит на стороне хостинга, поскольку сервер не доверяет пользовательским X-Forwarded-For.

Без API-ключа настоящая проверка ещё не работает. Тесты используют подставные ответы провайдера и не доказывают качество живой модели:

```sh
python3 -m unittest discover -s tests -q
```

Добавлены появления блоков при прокрутке, движение карточки профиля, декоративные орбиты, бегущая строка, наклон превью и эффекты кнопок. Настройка `prefers-reduced-motion` отключает движение.

## Статистика отзывов

Распределение оценок 5–1 показывает количество и долю от всех опубликованных отзывов. Сортировка «Сначала новые» учитывает дату и ID; «Сначала лучшие» — оценку, затем дату и ID. Переключение не меняет средний рейтинг и статистику и сохраняется при обновлении списка. При отсутствии отзывов полосы и счётчики нулевые.
