# Настройка Supabase + Python-хостинг

1. Создайте бесплатный проект на https://supabase.com/dashboard. Пароль базы сохраните у себя — приложению он не нужен.
2. Откройте SQL Editor, вставьте содержимое `schema.sql` и выполните запрос.
3. В настройках проекта найдите Project URL и API Keys. Нужен серверный Secret key (`sb_secret_…`), либо legacy `service_role`. Публичный `anon` / publishable key здесь не подходит.
4. На хостинге Python (например Render, Web Service) задайте секреты:
   - `SUPABASE_URL`: адрес вида `https://PROJECT.supabase.co`;
   - `SUPABASE_SECRET_KEY`: серверный ключ;
   - `MODERATION_API_KEY`: ключ OpenAI для существующей ИИ-модерации.
5. Команда запуска: `python3 server.py`. Внешних Python-зависимостей нет; если хостинг требует build command, используйте `python3 -m py_compile server.py`. Порт выдаётся хостингом через `PORT`. При добавлении Origin-прокси сохраняйте исходный Host.
6. Откройте сайт: сначала убедитесь, что список отзывов загрузился без ошибки. Затем отправьте настоящий отзыв и проверьте его наличие после перезапуска сервера и в другом браузере.

Supabase хранит отзывы; он не запускает этот Python-сервер. Для сайта нужен отдельный Python-хостинг. Домен покупать необязательно: можно использовать адрес хостинга. Бесплатные планы имеют ограничения и могут приостанавливать неактивные проекты — проверьте актуальные условия в панели провайдера.

Ключи не отправляйте в чат и не вставляйте в HTML или репозиторий. Ранее опубликованный Groq-ключ не используется. Поддержка Groq пока не реализована: текущая модерация использует OpenAI.

Без переменных Supabase используется локальная SQLite. Если указана хотя бы одна переменная Supabase, неполная настройка или сбой приводит к ошибке, а не записи в временную SQLite. Существующие локальные отзывы автоматически не переносятся; при необходимости их следует мигрировать отдельно.

Таблица закрыта для `anon` и `authenticated`, RLS включён. Публикация идёт через Python после модерации. Не добавляйте публичные INSERT-политики, иначе можно будет обходить проверку. При отсутствии ключа модерации новые отзывы не публикуются.
